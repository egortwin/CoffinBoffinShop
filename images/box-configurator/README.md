# Изображения конфигуратора шкатулки

Сюда добавляются изображения конфигуратора. Рекомендуемые имена:

- `box-background.webp` — общий фон с передней и задней сторонами шкатулки, 1000×1000 px.
- `front-ankh-*.png` — варианты анкха, прозрачный фон, холст 1000×1000 px.
- `back-tarot-*.png` — варианты карт Таро, прозрачный фон, холст 1000×1000 px.

Важно:
- Не обрезать PNG до размера самой вставки: сохранять весь холст 1000×1000.
- Положение и масштаб вставок должны совпадать с фоновым изображением.
- После добавления файлов прописать их относительные пути и названия в `config/box-configurator.js`.
- Для фотографий предпочтителен WebP; для вставок с прозрачностью — PNG.
